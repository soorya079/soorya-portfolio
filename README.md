# Soorya M // Cloud Engineering Lab

Interactive portfolio for Soorya M, a junior cloud engineer focused on AWS, Docker, networking, deployment, and troubleshooting.

## Run locally

```bash
npm install
npm run dev
```

Create a `.env` file from `.env.example` only when adding a verified contact email, resume URL, or optional GitHub token.

## Build

```bash
npm run build
npm run preview
```

The flagship CloudSentinel case study presents the verified deployment path: Python API, Docker, Amazon ECR, ECS Fargate, and CloudWatch.
